# Reconstruction scope and evidence

This is a retrospective reconstruction performed now, without backdating.
The represented project state follows formal first-parent evolution; additional
project parents identify exact trees inspected during this reconstruction.
They do not establish which commit an original session executed against.
Session-level commit provenance is incomplete and is not inferred from dates.

The authorized horizon includes eight archived Codex sessions whose initial
working directory is this project, from the early display and packaging work
through the late-July Org workflow and testing discussion. The long packaging
session also works in the nested Twist repository; those experiments explain
design choices but do not turn that repository into the main project.
Other-directory sessions are outside scope. Entire source horizons were surveyed
for substantive intervals before selecting recoverable states; user decisions,
corrections and relevant reported tool results were examined. Original records
remain the evidence, rather than encrypted compaction replacements. An
interrupted structural-session tail has no recoverable completion there.
A separate packaging session supplies relevant completed startup investigation.

Two user-supplied reference notes informed the architecture-led ordering.
Their useful context is incorporated into substantive memory; neither note
nor any full conversation is archived or assigned its own Auxiliary history.
Reference GAW practices from NixOS, org-texmacs and git-agent-workflow informed
organization only. No foreign repository history is associated.

Independent source histories distinguish display/startup contracts, dual-entry
packaging, Nix helper/grammar evolution, and Org workflow ownership. Their
selection reflects consequential decisions rather than one checkpoint per
session or edit. Formal memory adopts applicable knowledge at architecture
boundaries; source conclusions may precede or exceed the represented project
tree. Retention is not blanket adoption of every source assertion.

Present static inspection, historical tool reports and user-reported checks
are distinct evidence classes. No Emacs runtime, Nix build, dependency update
or network validation is performed by this reconstruction. Repository ancestry
and changed code support structural claims; they cannot establish runtime
success. Historical skips, interrupted work and proposed tests remain limits.

Before associating project history, its reachable blob/path closure was
screened for likely credentials and private keys; no candidate was found.
This pattern-based review is not a confidentiality guarantee. Source memory
is distilled and screened before writing and staging; raw logs, private paths
and personal note identifiers are omitted. Parent relationships and source
locations are recovered from Git rather than maintained as a parallel index.
